# Portfolio

A modern, animated personal portfolio website built with **React 19**, **Vite**, and **Tailwind CSS**.  
Showcasing my projects, skills, and journey as a frontend developer.

**Live Demo:** [thedeveloper-noman.vercel.app](https://thedeveloper-noman.vercel.app/)

---

## ✨ Features

- Smooth scrolling experience (Lenis)
- GSAP-powered animations and transitions
- Interactive project showcase with detailed info cards
- Responsive design for all screen sizes
- Dark theme UI
- Loading screen for a polished first impression
- Clean navigation and section-based layout
- SVG animations
- Project previews with images

---

## 🧩 Sections

- **Loader** – Animated loading screen
- **Navbar** – Smooth navigation across sections
- **Hero** – Introduction and main landing area
- **About** – Personal introduction and skills
- **Projects** – Showcase of featured work
- **Project Info Card** – Detailed view of selected projects
- **SVG Animation** – Visual animated elements
- **Footer** – Contact and links

---

## 🛠️ Tech Stack

| Technology          | Purpose                          |
|---------------------|----------------------------------|
| React 19            | UI library                       |
| Vite                | Build tool & dev server          |
| Tailwind CSS 4      | Styling                          |
| GSAP + @gsap/react  | Animations                       |
| Lenis               | Smooth scrolling                 |
| Redux Toolkit       | State management                 |
| Swiper              | Carousels / sliders              |
| Lucide React        | Icons                            |
